LECCIÓN 1.11 · SVD — BLOQUE 1: UNA MATRIZ HECHA DE CAPAS

POR QUÉ SVD
- Los autovectores solo sirven para matrices CUADRADAS.
- La SVD sirve para CUALQUIER matriz: usuarios × películas, imágenes,
  capas de una red…

LA IDEA
- tabla = capa 1 + capa 2 + capa 3 + …  (de más a menos importante)
- Cada capa = un patrón: "a estos usuarios les gustan estas películas".
- Valor singular = cuánto pesa cada capa (como los autovalores de PCA).
- Quedarse con las primeras capas = comprimir perdiendo muy poco.
- En código: U, S, Vt = np.linalg.svd(R)
  U = cada usuario en cada capa | S = pesos | Vt = cada película en cada capa

MI RECOMENDADOR (6 usuarios × 5 películas)
- Valores singulares: 17,37 · 7,54 · 1,57 · 0,84 · 0,38 → 2 capas importantes.
- Capa 1 = cuánto te gustan las películas en general.
- Capa 2 = acción (+) frente a romance (−). La SVD lo descubrió SOLA:
  películas: acción +0,31/+0,43/+0,30 | románticas −0,55/−0,56
  usuarios: Ana +0,51, Luis +0,43 | Marta −0,56, Pablo −0,49 | Sara −0,04, Iker −0,07
- Error medio: 1 capa → 1,16 puntos | 2 capas → 0,28 puntos
- A escala: 1.000 × 200 = 200.000 notas → 2 capas ≈ 2.400 números.
- Un recomendador usa las capas para predecir las notas que faltan.

APUESTAS: 2 capas importantes ✅ | Sara e Iker cerca de 0 ✅


LECCIÓN 1.11 · BLOQUE 2 — COMPRIMIR IMÁGENES Y LoRA

UNA FOTO ES UNA MATRIZ (brillo de cada píxel, 0–255)
- Foto de 427 × 640 = 273.280 números.
- Valores singulares: 83.442 · 15.393 · 9.760 … y el 400 vale 8.
  → las primeras capas pesan muchísimo más → se puede comprimir mucho.
- k capas ocupan k × (427 + 640 + 1) números:
  5 capas  →  2,0 % | error 20,7 | solo manchas
  20 capas →  7,8 % | error 14,7 | se reconoce, algo borrosa
  50 capas → 19,5 % | error 11,2 | casi como el original
- Primeras capas = formas grandes | últimas = detalles finos y ruido.

LoRA (Low-Rank Adaptation): ajustar un LLM tocando pocos pesos
- Al ajustar (fine-tuning), el CAMBIO de cada capa suele tener pocas capas.
- Mi simulación (capa de 1.000 × 1.000):
  valores singulares 1.071 · 1.058 · 989 · 902 · 6 · 6 … → 4 capas + ruido
- LoRA aprende cambio ≈ A × B (A: 1.000 × r, B: r × 1.000).
  r = 4 → 8.000 números en vez de 1.000.000 (0,8 %)
- Por eso se puede ajustar un LLM grande en una sola GPU.
- El parámetro r de LoRA (librería PEFT) = cuántas capas deja aprender.
  Típico: 4, 8, 16. Más r = más capacidad y más memoria.

APUESTAS: con 20 capas se reconoce ✅ (bien del todo con 50) | unos pocos valores grandes ✅ (4)
