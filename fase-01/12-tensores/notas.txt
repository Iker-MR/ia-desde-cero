LECCIÓN 1.12 · OPERACIONES CON TENSORES — BLOQUE 1: QUÉ ES UN TENSOR

TENSOR = tabla de números con cualquier número de dimensiones (ejes)
- 0 dim: nota ()  | 1 dim: alumno (2,) | 2 dim: clase (4, 2)
- 3 dim: colegio (3 clases, 4 alumnos, 2 asignaturas) = (3, 4, 2) → 24 números
- Total de números = multiplicar la forma.

FORMAS TÍPICAS
- Fotos (B, C, H, W) = (32, 3, 224, 224) → 4.816.896 números
- Texto (B, T, D) = (16, 128, 768): frases, tokens, embedding de cada token
- B = lote (batch), casi siempre el primer eje.

REDUCIR UN EJE (mean, sum, max…)
- El eje que pongo en axis DESAPARECE (se junta).
- TRUCO: "¿qué quiero juntar?" → ese es el axis.
- Colegio (3, 4, 2):
  axis=0 → juntar clases      → (4, 2)
  axis=1 → juntar alumnos     → (3, 2): media de cada clase por asignatura
  axis=2 → juntar asignaturas → (3, 4): nota media de cada alumno
- Embedding de una frase: (16, 128, 768).mean(axis=1) → (16, 768)

CAMBIAR DE FORMA
- reshape: mismos números, otra forma. El total tiene que coincidir.
  12 números: (3, 4) ✓ | (2, 2, 3) ✓ | (6, -1) = (6, 2) ✓ | (4, 4) ✗ | (5, 3) ✗
- -1 = "calcúlalo tú".
- v[None, :] → fila (1, 3) | v[:, None] → columna (3, 1) | squeeze quita ejes de tamaño 1

ERRORES QUE COMETÍ

LECCIÓN 1.12 · BLOQUE 2 — BROADCASTING Y EINSUM

BROADCASTING: operar con formas distintas
1. Alinear las formas POR LA DERECHA.
2. En cada columna: iguales, o uno de los dos es 1 (el 1 se estira).
3. Si a una le faltan ejes, se le añaden unos por la izquierda.
- (4, 3) + (3,)   → (4, 3): un extra por asignatura
- (4, 3) + (4,)   → ERROR: el 4 queda debajo del 3
- (4, 3) + (4, 1) → (4, 3): un extra por alumno (hay que usar una columna)

EL FALLO SILENCIOSO
- prediccion (3, 1) − real (3,) → (3, 3): todas con todas, SIN ERROR.
- Error cuadrático medio: correcto 0,03 | con el fallo 5,23 (≈ 175 veces más)
- Arreglo: prediccion[:, 0] o squeeze → (3,)
- Hábito: print(prediccion.shape, real.shape) antes de la pérdida.
  No ignorar el warning de nn.MSELoss en PyTorch.

EINSUM: una letra por eje
- Letras que desaparecen tras la flecha → se SUMAN.
- Letras que quedan → se conservan.
  "i,i->"         producto escalar (1.01)
  "ik,kj->ij"     matriz × matriz (1.02), la k se cancela
  "bik,bkj->bij"  un lote de multiplicaciones a la vez
  "ij->i"         suma de cada fila = sum(axis=1)

APUESTAS: (4, 3) ✅ | (4, 3) + (4, 1) → (4, 3) ✅ | (3, 1) − (3,) → (3, 3) ✅ |
  con el fallo, la pérdida muchísimo más grande ✅ (5,23 frente a 0,03)

ERRORES QUE COMETÍ
- (4, 3) + (4,): me atasqué; no encaja porque se alinea por la derecha.

LECCIÓN 1.12 · BLOQUE 3 — LA ATENCIÓN, FORMA A FORMA

LA IDEA: cada token mira a los demás
- "El gato se subió al árbol porque ÉL tenía miedo" → "él" mira a "gato".
- Como un buscador. Cada token genera:
  Q (pregunta): ¿qué busco? | K (etiqueta): ¿qué ofrezco? | V (contenido): qué entrego

LOS PASOS (B=2 frases, T=5 tokens, E=8 números, H=2 cabezas de D=4)
0. Entrada X                                (2, 5, 8)
1. Q, K, V = X @ W           (1.02)          (2, 5, 8)
2. Separar cabezas: reshape + transpose      (2, 2, 5, 4)
3. Puntuaciones = Q · K      (producto escalar, 1.01)
   einsum "bhtd,bhsd->bhts"                  (2, 2, 5, 5) ← cada token con cada token
4. Pesos = softmax por filas (1.06)          (2, 2, 5, 5) ← cada fila suma 1
5. Salida = pesos · V
   einsum "bhts,bhsd->bhtd"                  (2, 2, 5, 4)
6. Juntar cabezas + W_o                      (2, 5, 8)   ← ¡igual que la entrada!

LA TABLA DE ATENCIÓN (fila = token que mira, columna = token mirado)
- Mis pesos eran aleatorios: el token 4 miraba al 2 (0,73), el 5 al 1 (0,77)…
- En un modelo entrenado, "él" tendría un número grande en "gato".
- Entrenar un LLM = aprender W_q, W_k y W_v para que cada token mire bien.

POR QUÉ LA MISMA FORMA
- Se pueden apilar capas de atención: un LLM tiene decenas.

APUESTAS: puntuaciones (2, 2, 5, 5) ✅ | cada fila suma 1 ✅ | salida (2, 5, 8) ✅
