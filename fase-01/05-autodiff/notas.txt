LECCIÓN 1.05 · REGLA DE LA CADENA Y AUTODIFF — BLOQUE 1

QUÉ ES UN GRADIENTE
- Cuánto sube el resultado si un número sube 1 (un poquito).
- No es el valor del número: es cuánto influye en el resultado.

REGLAS LOCALES (cada operación solo sabe la suya)
- Suma: deja pasar el gradiente tal cual (×1).
- Producto: cada factor recibe lo que vale EL OTRO factor.
- Relu: ×1 si la entrada es positiva, ×0 si no (grifo abierto/cerrado).

REGLA DE LA CADENA
- Multiplicar lo que pasa en cada tramo del camino.
- Ejemplo tienda: (producto + envío) · cajas.
  Si el producto sube 1 €, el total sube 1 · nº de cajas.

BACKWARD (backpropagation)
- Empieza por el final con gradiente 1 (la semilla).
- Cada nodo reparte: lo que le llega × su tramo.
- Una sola pasada hacia atrás da TODOS los gradientes.
- Antes se ordena el grafo (orden topológico): cada nodo reparte
  solo cuando ya ha recibido todo lo suyo.

DETALLES IMPORTANTES
- grad += (no =): si una variable llega por varios caminos, se suman.
  y = x · x con x = 3 → 3 + 3 = 6 = 2x.
- Por eso en PyTorch hay que hacer optimizer.zero_grad() en cada paso.
- Neurona muerta: si la relu siempre recibe negativos, gradiente 0
  y deja de aprender.

RESULTADO
y = relu(x1·x2 + b), x1=2, x2=3, b=1  →  y = 7, gradientes 3, 2 y 1
Con x2 = -3                           →  y = 0, gradientes 0, 0 y 0

ERRORES QUE COMETÍ
- Envío en la tienda: dije +1 €, pero se paga en cada caja → +4 €.
- Una caja más: dije +4 €, pero cuesta lo que vale una caja → +3 €.
- dy/db en x1·x2 + b: el gradiente es 1, no el valor de b.
- El += : sirve para sumar los gradientes que llegan por varios caminos.


LECCIÓN 1.05 · BLOQUE 2 — MÁS OPERACIONES Y COMPROBACIÓN DE GRADIENTES

RESTA
- y = a - b  →  dy/da = +1, dy/db = -1.
- Gradiente negativo = si subes ese número, el resultado BAJA (como un descuento).
- En el código no tiene regla propia: a - b = a + (-1 · b).
  Se construye con suma y producto, y la regla de la cadena hace el resto.

POTENCIA
- Regla: x^n  →  n · x^(n-1)  ("baja el exponente y réstale 1").
- x² con x = 3 → 2 · 3 = 6 (igual que x · x).
- x³ con x = 2 → 3 · 2² = 12.
- Se usa en la pérdida: (predicción - real)².

TANH
- Aplasta cualquier número entre -1 y 1.
- Gradiente: 1 - tanh².  Vale 1 en x = 0 y casi 0 lejos de 0.
  x = 0 → 1      x = 2 → 0,0707      x = 5 → 0,0002
- SATURACIÓN: con valores grandes, la tanh se queda pegada a 1,
  el gradiente es casi 0 y la neurona aprende muy despacio
  (desvanecimiento de gradientes, como en la 1.03).

COMPROBACIÓN DE GRADIENTES (gradient check)
- Numérico: (f(x + h) - f(x - h)) / 2h  → mide moviendo x un poquito.
- No usa mis _backward, así que sirve de ÁRBITRO.
- Si autodiff y numérico coinciden (diferencia < 1e-5) → OK.
  Si no → hay un fallo en algún _backward.
- Experimento: rompí la tanh (1 - t en vez de 1 - t²):
    x³ + 2x + 1          → OK (no usa tanh)
    tanh(x³ + 2x + 1)    → ¡FALLO! (autodiff 0,077 vs numérico 0,153)
    (x - 3)² · tanh(x)   → ¡FALLO!
- Python NO dio ningún error: los gradientes salen mal en silencio.
- En x = 0 el fallo se escondía (1 - 0 = 1 - 0²) →
  comprobar siempre con varias fórmulas y varios valores.

ERRORES QUE COMETÍ
- Gradiente de la tanh: dije que era mayor en x = 5, pero es mayor en x = 0.
  El gradiente no es cuánto VALE la función, sino cuánto SE MUEVE.
- No sabía qué haría la comprobación al romper la tanh:
  el numérico no cambia, el autodiff sí, y por eso salta el FALLO.


LECCIÓN 1.05 · BLOQUE 3 — MI PRIMERA RED NEURONAL (XOR)

NEURONA
- neurona(x) = tanh(w1·x1 + w2·x2 + ... + b)
- Pesos (w) y sesgo (b) = lo que la red APRENDE (son objetos Valor).
- Capa = lista de neuronas con las mismas entradas.
- Red = capas en fila: la salida de una es la entrada de la siguiente.

CONTAR PARÁMETROS
- Cada neurona: un peso por entrada + 1 sesgo.
- Red([2, 4, 1]):  oculta 4 × (2 + 1) = 12  |  salida 1 × (4 + 1) = 5  →  17
- Red([3, 5, 1]):  oculta 5 × (3 + 1) = 20  |  salida 1 × (5 + 1) = 6  →  26

XOR
- Salida 1 si las entradas son distintas, -1 si son iguales.
- Una neurona solo separa con una LÍNEA RECTA, y en XOR no hay
  ninguna línea que separe las dos diagonales → hace falta capa oculta.
- Históricamente se usó para decir que las redes no servían.
  Lo resolvió la backpropagation.

BUCLE DE ENTRENAMIENTO (los mismos 4 pasos de la 1.04)
1. Hacia delante: predicciones y pérdida
2. Gradientes a 0 (por el +=)
3. perdida.backward()   ← ANTES lo deducía a mano (2·error·x)
4. p.dato -= tasa * p.grad

RESULTADOS
