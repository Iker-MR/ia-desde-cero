# IA desde cero

Mi recorrido como desarrollador full stack aprendiendo ingeniería de IA desde los fundamentos,
siguiendo el curso abierto [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch).

Cada algoritmo se implementa primero a mano (matemáticas puras en Python) y después con las
librerías de producción (NumPy, PyTorch).

## Progreso

| Fase | Tema | Estado |
|------|------|--------|
| 0 | Entorno, Git, GPU, APIs de LLMs, datos, depuración, Python para IA | ✅ |
| 1 | Fundamentos matemáticos | 🚧 en curso |

## Estructura

Cada lección tiene su carpeta (`fase-XX/NN-tema/`) con el código que he escrito y mis notas.

## Destacado

- **fase-00/04-apis**: llamadas a Claude con el SDK y con HTTP puro, manejo de errores y tokens.
- **fase-00/12-debug**: detección de NaN silenciosos y profiling de cuellos de botella.
